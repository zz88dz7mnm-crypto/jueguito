# Clínica Michi

Juego de gestión de tiempo inspirado en *Garfield's Pet Hospital*. Atendé mascotas en una clínica veterinaria:

1. Tocá una mascota de la sala de espera y llevala al **Consultorio** para diagnosticarla.
2. Llevala a cada estación de tratamiento que necesite (Medicina, Vendajes, Baño, Rayos X, Cirugía).
3. Cobrá en la **Caja**. Cuanta más paciencia le quede, más propina deja. Las VIP 👑 pagan el doble.
4. Si Michi se duerme en una estación, tocalo para despertarlo.

Entre días, usá las monedas en la tienda para comprar estaciones, mejorar la velocidad, sumar sillas, decorar o contratar una enfermera.

Para jugar, abrí `index.html` en el navegador. `game.html` es la misma página sin el esqueleto HTML, para publicarla como Artifact.
